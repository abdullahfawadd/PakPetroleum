## 2024-06-03 - AdaptiveDpr configuration in React Three Fiber v8+
**Learning:** In React Three Fiber v8+, `AdaptiveDpr` does not function autonomously. The built-in performance monitor from earlier versions was removed. `AdaptiveDpr` relies on a performance state (which drops below 1 during frame rate drops). Without wrapping the scene or `AdaptiveDpr` component in Drei's `<PerformanceMonitor>`, `AdaptiveDpr`'s internal `performance.current` value never changes from 1, rendering the optimization completely inactive.
**Action:** When implementing `AdaptiveDpr` in R3F v8+, always ensure the scene or the component is wrapped inside a `<PerformanceMonitor>` from `@react-three/drei` so that performance drops trigger the necessary state changes for dynamic resolution scaling.
